# astroceleste

[![crates.io](https://img.shields.io/crates/v/astroceleste.svg)](https://crates.io/crates/astroceleste)
[![docs.rs](https://img.shields.io/docsrs/astroceleste)](https://docs.rs/astroceleste)
[![CI](https://github.com/ffalcinelli/astroceleste-cli/actions/workflows/ci.yml/badge.svg)](https://github.com/ffalcinelli/astroceleste-cli/actions/workflows/ci.yml)
[![License: MIT OR Apache-2.0](https://img.shields.io/badge/License-MIT%20OR%20Apache--2.0-blue.svg)](https://github.com/ffalcinelli/astroceleste-cli)

Command-line interface for [Astroceleste](https://astroceleste.it) and its astrological calculation core, [astroceleste-engine](https://github.com/ffalcinelli/astroceleste-engine).

> **Experimental (0.0.x):** This crate is currently in its initial reservation and experimental phase.

## Installation

```bash
cargo install astroceleste
```
